Переменные и область применения переменных

Как и любой другой язык программирования, GML использует переменные в качестве основной единицы для большинства операций программирования. Переменные используются для хранения информации в памяти устройства для последующего (или мгновенного) использования, и им присваивается имя, чтобы вы могли ссылаться на них во время выполнения и в функциях сценария. Переменная в GML может хранить множество различных типы данныхНапример, вещественное число (например: 100, 2.456575, -56 и т.д.), строка (например: "Hello world!"), целое число (например: 1, 556, -7), булево число (true или false), а также другие вещи:

var _num = 126.4545;
var _str = "Hello World";
new_num = _num * 100;
global.my_string = _str + " I said";

Вы также можете использовать переменные для хранения значений, возвращаемых функциями, например:

var _id = instance_nearest(x, y, obj_Tree);
root = sqrt(1000);
global.str = string_upper("Hello World");

Итак, переменная - это то, что мы можем назвать и использовать для хранения значения с целью последующего использования в одной или нескольких операциях. Отличным примером переменной в реальном мире является pi 𝜋 . .. это переменная, которую знают все, и она хранит значение 3.14159265 (и т.д...). Почему мы используем ее в нашем языке? Ну, гораздо проще сказать кому-то "пи", чем "три точки один четыре один пять девять два шесть пять"! Именование вещей подобным образом делает жизнь намного проще, а также означает, что если значение переменной изменится, нам не придется менять число везде, так как имя переменной останется прежним.

При формировании переменных в GML они должны иметь имя, которое начинается с буквы или символа подчеркивания "_" и может содержать только буквы, цифры и символ подчеркивания '_' с максимальной длиной 64 символа. Таким образом, допустимыми переменными являются такие, как fish, foo_bar, num1 или _str, а недопустимыми - 6fish, foo bar или *num.

Во многих языках программирования необходимо создать переменную "присвоением", прежде чем вы сможете ее использовать. В основном это означает, что вы сообщаете компьютеру имя, которое хотите использовать для переменной, и присваиваете ей начальное значение. Затем переменной отводится место в памяти для хранения значения или выполнения операций над ним. Присвоение переменной имеет вид:

<variable> = <expression>;

Выражение может быть простым значением, но может быть и более сложным, поэтому вместо присвоения значения переменной можно также добавить значение к текущему значению переменной, например, с помощью +=:

a = 100;   // Assigning a simple value
b = 200;
c = 300;
a += b;    // Assigning with operation
a = b + c; // Assigning with expression

ПРИМЕЧАНИЕ GameMaker Language также может принимать ":=" для назначений, хотя это, как правило, не самый распространенный способ:

<variable> := <expression>;

Аналогично можно вычитать с помощью -=, умножать с помощью *=, делить с помощью /=, или использовать побитовые операторы с помощью |=, &= или ^=. Вы также можете прибавить или отнять единицу от значения с помощью ++, --. Дополнительную информацию см. в разделе " Выражения и операторы".

Обратите внимание, что вы не можете сделать следующее (или любую другую вариацию):

a = b = c = 4;

Вместо этого следует сделать так:

a = 4;
b = 4;
c = 4;

Все переменные, показанные выше, являются переменными экземпляра , однако в программировании с помощью GameMaker существуют еще три основные категории переменных, и каждая из них имеет свою область применения (которую можно рассматривать как область действия, или область охвата). Различные виды переменных и их область действия описаны на следующих страницах:

  • Переменные экземпляра
  • Глобальные переменные
  • Константы

На сайте GameMaker Language также имеется несколько различных встроенных переменных, которые могут иметь любую из перечисленных выше областей видимости (кроме локальной). Эти переменные являются особенными, поскольку они включены по умолчанию в состав объектов и комнат в игровом мире. Некоторые встроенные глобальные переменные перечислены в упомянутом выше разделе, а в различных частях руководства для sprites, комнат, объектов и т.д... также описаны встроенные переменные, доступные в каждом случае. Примерами таких встроенных переменных экземпляра могут быть:

  • sprite_index
  • path_scale
  • speed

Примерами встроенных глобальных переменных могут быть:

  • view_xport
  • GM_version
  • room

Большинство встроенных переменных можно изменять и устанавливать, как и другие переменные, а некоторые даже могут быть массивами, только для их создания не нужно устанавливать их, как обычные переменные, поскольку они уже будут инициализированы значением по умолчанию.
